# Тихон — диалог

Статическая страница розыгрыша с пустым чатом в стиле Viber и повторяющимся скримером. Интерфейс на русском. Это локальный макет, не подключённый к Viber: сообщения, звонки и вложения не отправляются, вход в аккаунт не требуется.

## Поведение

- При открытии видно меню «Чаты» с карточкой **Тихон** и кнопкой **«Открыть диалог»**. До нажатия нет таймера и звука.
- Нажатие кнопки открывает пустой диалог, разблокирует Web Audio и запускает отсчёт. Через **3 секунды после нажатия** появляется скример со звуком. Кнопка также работает с клавиатуры (Enter/Пробел).
- Звук активируется непосредственно в обработчике нажатия, как требуют мобильные браузеры. Громкость устройства и ограничения браузера продолжают действовать; если звук недоступен, изображение всё равно появится. Повторные нажатия не накладывают звуковые дорожки.
- Поле ввода позволяет набрать только локальный черновик; он не сохраняется и никуда не отправляется. Остальные значки декоративные.
- Крик длительностью 2,5 секунды повторяется одним Web Audio-источником. Громкость сайта — **100%** (`AUDIO_GAIN = 1`); PCM нормализован до пика 0,99. Физическая громкость зависит от устройства. Перед проверкой уменьшите громкость устройства, особенно в наушниках.
- Две инверсии изображения по 100 мс в каждом цикле 2,5 секунды. При системной настройке уменьшения движения (`prefers-reduced-motion: reduce`) вспышек нет.
- Кнопок выключения звука и закрытия эффекта нет. Escape ничего не запускает и не закрывает. Обычные команды браузера не блокируются.
- Закрытие страницы или переход на другую вкладку отменяет таймер и останавливает эффект со звуком. При возврате показано меню, автоматического повторного запуска нет. Для нового розыгрыша снова нажмите «Открыть диалог».
- Нет регистрации, cookies, localStorage, трекеров, внешних API, шрифтов и библиотек. Все ресурсы хранятся в репозитории. GitHub может вести собственные технические журналы запросов.

## Файлы

```text
index.html              — меню, русский интерфейс чата и область скримера
styles.css              — адаптивный чат и вспышки
app.js                  — таймер на 3 секунды, звук и остановка при уходе
assets/scare-face.jpg    — кадр из предоставленного ролика
assets/scare-audio.js    — оригинальный крик в PCM16, моно, 44100 Гц
assets/icon.svg          — локальная иконка диалога
.nojekyll               — публикация статических файлов без Jekyll
tests/game.test.cjs      — автоматические проверки
```

Исходный MP4 не включён. Использованы 8-й кадр и аудиофрагмент с отметки 0,233 с продолжительностью 2,5 с. `assets/visitor.svg` — неиспользуемая иллюстрация прежней версии.

## Локальный запуск

Откройте `index.html` двойным щелчком или запустите из папки проекта:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Затем откройте `http://127.0.0.1:4173`. Сервер и Python нужны только для такого локального просмотра. Сборки и установки npm-зависимостей нет.

## GitHub Pages

Репозиторий: https://github.com/TixonGamer/viber

Сайт: https://tixongamer.github.io/viber/

1. В репозитории откройте **Settings → Pages**.
2. Выберите **Deploy from a branch → main → /(root) → Save**.
3. Дождитесь публикации в **Actions**, затем нажмите **Visit site**.

Настройка выполняется один раз. Последующие обновления публикуются после commit и push в `main`:

```sh
git add index.html styles.css app.js assets README.md tests
git commit -m "Update chat page"
git push origin main
```

Все пути относительные, поэтому сайт работает в подпапке репозитория. Если браузер показывает старую версию, обновите страницу с Ctrl+F5.

## Проверка и настройка

```sh
node --check app.js
node --test tests/game.test.cjs
```

10 тестов проверяют ожидание кнопки, показ через 3 секунды после нажатия, активацию звука, защиту от двойного запуска, повтор без накопления источников, недоступный звук, выход со страницы, позднее разрешение звука и повторное открытие диалога.

В `app.js` меняются `TRIGGER_DELAY` и `AUDIO_GAIN`. Период вспышек задан в `styles.css`. Эмуляция и локальные проверки не заменяют тестирование на физическом iPhone; физический iPhone отдельно не проверялся.
