# Оттенок

Готовая статическая мини-игра с неожиданным финалом. HTML, CSS, JavaScript, кадр и оригинальный крик из предоставленного пользователем ролика. Без сборки, зависимостей, сервера, внешних API, шрифтов и трекеров.

## Как работает

Нажмите «Начать» и ищите квадрат другого оттенка. Правильный ответ меняет поле и увеличивает счёт. Через случайные **8–12 секунд** после запуска появляется лицо из ролика на чёрном фоне поверх всей страницы. **Скример и звук повторяются без ограничения времени**, пока не закрыть эффект, не уйти с вкладки или не закрыть страницу. После закрытия эффекта появляется сообщение о розыгрыше. «Повторить игру» сбрасывает счёт и выбирает новую задержку.

- Оригинальный крик хранится локально в `assets/scare-audio.js`: 2,5 секунды PCM16, моно, 44100 Гц. Он зациклен одним источником Web Audio API, без накопления плееров или таймеров. Контекст разблокируется непосредственно при нажатии кнопки. Если Web Audio или запись недоступны, игра работает без звука. Встроенного YouTube-плеера нет.
- Кнопка звука доступна до начала, во время игры и поверх эффекта. Выключение останавливает звук, повторное включение во время скримера снова запускает звуковой цикл. Состояние сохраняется между раундами в памяти вкладки. После перезагрузки звук снова включён.
- «Закрыть» или Escape немедленно убирают эффект и останавливают звук. «Завершить» и Escape во время игры отменяют ожидающий эффект.
- При скрытии вкладки или уходе со страницы раунд и звук прекращаются. Для продолжения нужно явно начать новый раунд.
- В каждом цикле длительностью 2,5 секунды происходят две короткие инверсии изображения по 100 мс: на 0,5 и 1,5 секунды. Анимация повторяется до закрытия эффекта. При `prefers-reduced-motion: reduce` вспышки отключены. Частое мигание исходного видео заменено этой последовательностью. Принудительного системного Fullscreen нет; панель браузера остаётся доступна.
- По запросу владельца громкость сайта выставлена на **100%** (`AUDIO_GAIN = 1`). Исходный звук нормализован до пика 0,99, без дополнительного цифрового перегруза; начало и конец кратко сглажены. Физическая громкость зависит от устройства. Эффект громкий: перед проверкой уменьшите громкость устройства, особенно в наушниках.
- Интерфейс адаптирован под телефон, планшет и компьютер. Доступны клавиатура, видимый фокус, Escape и удержание фокуса внутри эффекта; сама игра рассчитана на различение цветов.
- Приложение не использует cookies, localStorage, аналитику, формы и сетевые API. GitHub как хостинг может вести собственные технические журналы запросов.

## Файлы

```text

styles.css          — адаптивное оформление

assets/scare-audio.js — оригинальный крик, локальные PCM-данные
assets/visitor.svg  — прежний рисунок (не используется)
assets/icon.svg     — локальный значок сайта
.nojekyll           — публикация статических файлов без Jekyll
tests/              — автоматические проверки логики
```

## Локальный запуск

Можно открыть `index.html` двойным щелчком. Для проверки через HTTP из папки проекта:

```sh
python -m http.server 4173 --bind 127.0.0.1
```

Откройте `http://127.0.0.1:4173`. Python нужен только для локального просмотра; на GitHub Pages он не нужен.

## Отправка в GitHub

Создайте пустой репозиторий на GitHub. Для GitHub Free выберите Public. Если репозиторий уже существует, используйте его адрес; не применяйте force push.

В терминале в папке проекта выполните, подставив свой логин и имя репозитория:

```sh
git add index.html styles.css app.js assets .nojekyll .gitignore README.md tests
git commit -m "Add complete shade game with surprise ending"
git remote add origin https://github.com/USERNAME/REPOSITORY.git
git push -u origin main
```

Если `origin` уже настроен, пропустите `git remote add`. Если файлы уже закоммичены, пропустите первые две команды. При отклонении push из-за существующей истории сначала согласуйте историю репозитория, не перезаписывайте её.

## Включение GitHub Pages

1. Откройте репозиторий на GitHub → **Settings → Pages**.
2. В **Build and deployment → Source** выберите **Deploy from a branch**.
3. Выберите **main** и **/(root)**, затем **Save**.
4. Дождитесь успешного `pages build and deployment` во вкладке **Actions** (публикация может занять до 10 минут).
5. В **Settings → Pages** нажмите **Visit site**. Обычный адрес: `https://USERNAME.github.io/REPOSITORY/`. Для репозитория `USERNAME.github.io` адрес будет `https://USERNAME.github.io/`.

Все пути относительные (`./assets/...`), поэтому сайт работает и в подпапке репозитория. Никаких секретов, токенов или переменных окружения не требуется. После изменений достаточно commit и push в `main`.

Официальная инструкция: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## Проверки

```sh
node --check app.js
node --test tests/game.test.cjs
```

Тесты используют встроенные средства Node.js, виртуальные часы, DOM-заглушку и Web Audio-заглушку; установка npm-пакетов не нужна. Они проверяют задержку, продолжительность, счёт, повтор, отмену, звук и уход со страницы. Для реального браузера проверьте отдельно:

1. Без «Начать» ничего не происходит даже спустя 12 секунд.
2. После старта поле реагирует, через 8–12 секунд показывается эффект. Он не исчезает автоматически: звук и анимация продолжают повторяться до закрытия.
3. Отключённый звук остаётся выключенным при повторе. «Закрыть» и Escape останавливают эффект сразу.
4. Переключение вкладки отменяет раунд. На возврате ничего не запускается автоматически.
5. На телефоне кнопки доступны, нет горизонтальной прокрутки; повторный раунд запускается корректно.

Точные параметры находятся в начале `app.js`: `MIN_DELAY`, `MAX_DELAY`, `AUDIO_GAIN`. Чтобы сделать звук тише, уменьшите `AUDIO_GAIN`, например до `0.25`. Звуковой цикл равен длине записи; период анимации задан в `styles.css`.

Использован 8-й кадр исходного видео и звук с отметки 0,233 с продолжительностью 2,5 с. Исходный MP4 в репозиторий не включён. JPEG и PCM подготовлены локально; для посетителя не нужны FFmpeg, npm или внешние сервисы.

### Результат проверки проекта

- 13 автоматических тестов Node.js: успешно, включая продолжительный повтор, отсутствие накопления источников, закрытие во время активации звука, отключение и повторное включение звука.
- Chrome: запуск настоящего AudioContext по клику, верный ответ, повтор, выключение звука, Escape, «Закрыть», отмена таймера — успешно; ошибок JavaScript нет.
- Ширины 320, 390, 768 и 1440 px: проверены в браузере, горизонтальной прокрутки нет. Проверены сенсорные нажатия и режим уменьшенного движения.
- Загрузка из подпапки `/repository/` и прямое открытие `index.html`: успешно. В сети — только собственные HTML/CSS/JS/JPEG/SVG-файлы.
- Safari на физическом iPhone и другие реальные телефоны отдельно не проверялись; мобильная проверка выполнена эмуляцией Chrome.
